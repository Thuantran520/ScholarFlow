## 🇬🇧 ENGLISH

### Extension Name
`ScholarFlow – Academic Research Assistant`

### Short Description (Summary — max 250 characters)
```
All-in-one academic assistant: IEEE/APA/Harvard/MLA/BibTeX citations, full-page scrolling screenshots, privacy redaction & Cookie Manager. 5 languages. Zero data collection.
```

### Detailed Description
```
ScholarFlow is an advanced browser extension built for students, researchers, and academics. All processing happens 100% locally on your device — no servers, no accounts, no data collection.

✦ ACADEMIC CITATIONS (Tab 1)
• Auto-extract metadata (title, authors, DOI, date) from any webpage with a single click.
• Supports 6 international citation styles: IEEE 2026, APA 7th Ed., Harvard, MLA 9th Ed., BibTeX, In-text.
• Verify citation credibility against Crossref (150M+ records), OpenAlex (250M+ works), and the DOI Foundation.
• Save your bibliography locally and export as a .bib file ready for LaTeX / Overleaf.

✦ PRIVACY REDACTION (Tab 2)
• Select and redact sensitive elements on any webpage: blur, blackout, pixelate, or hide entirely.
• Perfect for safe screen sharing in meetings, live streams, or publishing screenshots without exposing private data.

✦ SCREENSHOT & SCREEN RECORDING (Tab 3)
• Full-page scroll capture — even for infinitely long pages.
• Precision element or region capture on any page.
• Screen video recording (WebM) with optional tab audio.

✦ COOKIE MANAGER
• View, copy, export (JSON / string) and import cookies for the current website — all on demand.
• Cookies are never transmitted outside your browser.

✦ MULTILINGUAL SUPPORT
Vietnamese 🇻🇳 | English 🇬🇧 | 中文 🇨🇳 | Русский 🇷🇺 | 日本語 🇯🇵
Language can be changed instantly from the header — preference saved automatically.

✦ PRIVACY-FIRST & OPEN SOURCE
• Zero remote servers — Zero behavioral analytics — Zero ads.
• GDPR & CCPA compliant. Open source under the MIT License.
• No eval(), no inline scripts, no external CDN libraries. Passes Mozilla's automated security linter with 0 errors.
```
