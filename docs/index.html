Browser Extension

Academic research helper for citation, screenshots, and privacy protection.

ScholarFlow helps researchers capture metadata, generate citations in major formats, redact sensitive parts of a page, and save academic references without leaving the browser.

Key capabilities

  • IEEE / APA / Harvard / MLA / BibTeX
  • Webpage and PDF metadata extraction
  • Smart full-page and element capture
  • Redaction/blur for private content
  • Source verification and bibliography management

What ScholarFlow does

Academic citation

Generate references in standard formats and keep your research workflow close to the source page.

Privacy protection

Blur, blackout, or hide sensitive content before capturing or sharing a webpage.

Smart capture

Capture full pages, tall tables, or selected elements with a cleaner output for documentation.

How it works

1

Open a webpage

ScholarFlow reads the active page metadata and helps you build a clean academic profile.

2

Capture or redact

Select content to hide, capture a region, or take a full-page screenshot.

3

Export and reuse

Copy citations, save bibliography entries, and package the extension for release.

Release workflow

The project supports packaging for Chrome/Edge and Firefox variants. The repo includes manifest files and packaging scripts so the extension can be generated for browser store submission.
