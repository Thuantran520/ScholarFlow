# Bảng Mã Lỗi (Error Codes) - TakaExtension

| Mã Lỗi (Code) | Loại (Type) | Mô tả (Description) | Cách xử lý (Resolution) |
| :--- | :--- | :--- | :--- |
| **ERR_001** | Lỗi Dữ Liệu | Danh mục trích dẫn đang trống. | Vui lòng lưu ít nhất một tài liệu trước khi xuất/copy. |
| **ERR_002** | Cảnh Báo | Không tìm thấy thông tin tác giả/ngày tháng. | Hãy nhập thủ công hoặc dùng tính năng Xác minh. |
| **ERR_003** | Lỗi Mạng | Không thể kết nối tới máy chủ (Crossref, OpenAlex...). | Kiểm tra lại đường truyền internet. |
| **ERR_004** | Lỗi Quyền | Không có quyền quay màn hình hoặc chụp ảnh. | Cấp quyền cho tiện ích trong cài đặt trình duyệt. |
| **ERR_005** | Lỗi Xử Lý | Không thể trích xuất thông tin từ trang web này. | Trang web không hỗ trợ định dạng chuẩn. |
| **ERR_006** | Lỗi Bộ Nhớ | Vượt quá dung lượng lưu trữ cục bộ. | Xóa bớt các mục cũ trong danh mục. |
| **ERR_007** | Lỗi Format | Định dạng DOI không hợp lệ. | Kiểm tra lại chuỗi DOI nhập vào. |
| **ERR_008** | Lỗi Tải Về | Tải file (PDF, Bib, Video) thất bại. | Kiểm tra quyền tải file của trình duyệt. |
| **ERR_999** | Lỗi Không Xác Định | Lỗi hệ thống phát sinh chưa phân loại. | Liên hệ nhà phát triển (Minh Thuận). |
